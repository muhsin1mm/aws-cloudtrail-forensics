# Cloud-Based Log Monitoring & Security Analysis using AWS

## Introduction
This project monitors AWS user activity using CloudTrail logs.

## Objectives
- Detect suspicious logins
- Analyze root account activity
- Monitor repeated IP access
- Improve AWS security

## Services Used
- AWS CloudTrail
- Amazon S3
- Amazon CloudWatch
- Python

## Working Process
1. CloudTrail collects logs
2. S3 stores logs
3. CloudWatch monitors logs
4. Python analyzes logs

## Output
- Suspicious IP detection
- Root login alerts
- MFA warnings
- Dependency checks

## Conclusion
This project improves cloud security through automated log analysis.
